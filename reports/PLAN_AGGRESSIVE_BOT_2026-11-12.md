# 计划：激进实验机器人（合约 + 杠杆，只跑模拟盘）（2026-11-12）

**这只是计划。** 还没写代码，也没跑任何测试。不是投资建议。

## 零、定位和底线

- **它是什么：** 一个专门试「高风险、高波动」做法的研究机器人。跑在家用电脑上，**永远是模拟盘**，和云服务器上的 X7Safe、V3 完全分开。
- **它不是什么：** 不是 X7Safe 的替代品，也不在 12-20 的评估范围里。云服务器上冻结的规则一律不动。
- **底线（任何方案都要满足）：**
  1. 只跑模拟盘，不填 API key；
  2. 逐仓（isolated）保证金，单笔亏损最多亏掉那一笔的保证金，不会牵连整个账户；
  3. 杠杆最高 5 倍；
  4. 账户回撤到 40% 就自动停止开新仓，等人看过再说；
  5. 先预注册、再回测，回测通过才上家用模拟盘；
  6. 一次只测一个方案。

## 二、候选方案（推荐先做 A）

### 方案 A：NFI X7 合约版（多空 + 3 倍杠杆）+ 改过的安全层【推荐】

- **基础和来源：**
  - NFI 原作者本来就维护合约模式。X7 里有完整的做空规则（96 处做空入场相关代码）、`futures_mode_leverage = 3.0`、合约专用的止损线（`stop_threshold_futures`、`stop_threshold_doom_futures`）。
  - 上游仓库有现成的 `trading_mode-futures.json`、`pairlist-backtest-static-binance-futures-usdt.json`、`pairlist-static-binance-futures-usdt.json`。
- **为什么推荐：**
  - 代码、回测工具、对账方法、家用服务器部署方式都是现成的，改动最少；
  - 能和现货版 X7Safe 直接比：同一套规则，加了杠杆和做空之后到底好多少、险多少。
- **要改的地方（安全层要重新设计，不能照搬）：**
  1. **止损口径会变：** 合约模式里，freqtrade 的盈亏比例是按保证金算的（已经乘了杠杆）。现货版的「−25% 止损」放到 3 倍杠杆上，等于价格只跌 8.3% 就止损。所有安全层阈值都要按「价格跌幅」重新换算，再决定合约版用多少。
  2. **离强平要有距离：** 3 倍逐仓大约在价格反向走 30% 左右时强平（扣掉维持保证金会更近）。规则：止损触发点离强平价的距离，至少要有止损距离的一半，保证先止损、不会被强平。
  3. **资金费率：** 持仓越久成本越高，回测要用真实资金费率。NFI 的 grind（越跌越补）在合约上要特别看这部分成本。
  4. **多空数量上限：** 用 X7 自带的 `futures_max_open_trades_long/short`，例如各 3 笔，防止全部押在一个方向。
- **要测的变体：** 杠杆 1 倍（对照：只看做空和合约本身的影响）、2 倍、3 倍（NFI 默认）。5 倍只在 3 倍通过后才测。

### 方案 B：海龟 T2 的多空合约版（日线，2～3 倍）

- **基础和来源：**
  - 我们自己的 `tools/experiments/t2_turtle.py`。原始海龟规则本来就是多空双向的。
  - T2 只做多时没通过（`reports/T2_TURTLE_2026-11-09.md`）：熊市里没有交易机会，在震荡市里又被来回打止损。
- **为什么值得试：**
  - 「天气开关」在 BTC 位于 200 日均线以下时，从「不交易」改成「只做空」，熊市里也能有收益；
  - 日线策略，CPU 占用几乎为零，适合家用电脑长期挂着。
- **风险：** T2 在震荡市被来回止损的问题，加了杠杆会被放大。所以 B 的标准里要专门看震荡区间的回撤。
- **工作量：** 模拟器要加做空、资金费率和强平。不用 freqtrade，先在自己的模拟器里回测；通过了再写成 freqtrade 策略上模拟盘。

### 方案 C（参考，先不做）：freqtrade 官方示例合约策略

- 官方 `freqtrade-strategies` 仓库的 `futures/` 文件夹里有：FAdxSmaStrategy、FOttStrategy、FReinforcedStrategy、FSampleStrategy、FSupertrendStrategy、TrendFollowingStrategy、VolatilitySystem。
- 这些都是教学示例，没有长期验证过，也不像 NFI 那样有人持续维护。只在 A、B 都不行时，挑 FSupertrend 或 VolatilitySystem 当第三个候选。

### 不做的

- **资金费率套利：** 之前已经研究过（只留在本地，不上传）。它本质上是低风险做法，不是这个机器人的方向。
- **期权：** 原因见第一节。

## 三、怎么验证（预注册时再把数字定死）

1. **数据：** 用 `freqtrade download-data --trading-mode futures` 下载币安 U 本位合约的 5m/15m/1h/4h/1d K 线、标记价格和资金费率，存在 D 盘。和现货一样的回测窗口：L（约 20 个月）、R（最近 2 个月）。数据够的话，加一个包含 2022 年熊市的长窗口。
2. **成交成本：** 按对账实测的 +0.70% 开仓成本计算，外加合约手续费（挂单 0.02%、吃单 0.05%，以当时币安公布的为准）和资金费率。
3. **对照组：**
   - 现货 X7Safe（同一时间段）；
   - BTC 持有；
   - 同一方案的 1 倍杠杆版（用来分清收益来自「做空 / 合约」，还是来自「杠杆」）。
4. **通过标准（草案，预注册时定死）：**
   - 回测里没有任何一笔被强平；
   - 最大回撤 ≤ 40%；
   - 每单位回撤换来的年化收益，比现货 X7Safe 好；
   - 去掉最赚钱的 3 笔后，仍然赚钱（防止靠运气）；
   - 最近 2 个月（R）不能比现货 X7Safe 差很多。
5. **回测规则不变：** 一次只跑一个长回测，开 `FT_LOWMEM=1`，虚拟内存剩余 ≥ 36 GB 才跑。

## 五、要先说清楚的风险

- **杠杆会放大一切：** 3 倍杠杆下，价格跌 10% 就是本金亏 30%。回测好看也不代表实盘安全：急跌时的滑点、交易所限仓、插针，模拟盘都模拟不完整。
- **模拟盘会偏乐观：** 合约模拟盘不会真的被强平，插针时的成交也会比实际好。所以它的结果只能当作「上限参考」。
- **地区和合规：** 合约和期权的可用性取决于你所在的地区和交易所规定。真要考虑实盘之前，必须先确认你所在地允许使用这类产品。**这份计划只做模拟盘研究。**
